# Changelog

## 1.0.0

- Standalone Go executables for Windows, Linux and macOS on x64 and ARM64.
- Embedded minimal Compose template and pinned stable Android toolchain.
- CLI and bounded JSON stdin/stdout interfaces, with no interactive prompts.
- Native agent-home installation without Python, Node, or dependency downloads.
- Exclusive destination reservation, refusal to overwrite, and scoped rollback.
- Agent workspace containment with resolution of existing symlink ancestors.
- Display-name escaping for Android resources; safe Gradle project name and fixed Kotlin theme identifier.
- Package, SDK-range, unknown-field, and null-input validation.
- Official generated Gradle 9.6 wrapper with verified JAR and distribution hashes.
- Generator metadata, dry run, SDK-path option, and generated build/test instructions.
- Unit regression tests, real-engine integration, Android build validation workflow,
  platform ZIPs, source ZIP, licensing, checksums and setup guide.
